AI & storage settings

This standalone file has no built-in AI or cloud save — everything runs in this browser. Grading progress and files are saved to this device automatically (via IndexedDB); AI suggestions need your own Anthropic API key below.

Your key is stored only in this browser (localStorage) and sent directly to Anthropic's API — never anywhere else — when you use AI suggestions. Don't enter it on a shared or public computer; anyone with access to this browser's dev tools could read it.

The lab document, rubric, every submission's file, extracted text, and grading progress are all saved to this browser automatically. They stay on this device only — clearing your browser data or switching computers loses them.
